# PhD research

I am working  on the development of new methods for model reduction to accelerate simulations for predicting the evolution of CO2 injection in underground reservoirs. 

The associated models are formulated as flow equations in porous media with the presence of faults, leading to parameterized variational inequalities. The goal is to rapidly obtain an approximation of the solution for a wide range of parameter values that the problem depends on (fault network geometry, geological composition of the subsurface, etc.). The model reduction methods considered are non-linear approaches implementing neural networks and greedy algorithms.
